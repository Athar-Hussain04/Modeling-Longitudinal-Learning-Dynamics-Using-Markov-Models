Modeling Longitudinal Learning Dynamics Using Markov Models

A Python implementation of the VaSSTra method (Variables to States to Trajectories) that models longitudinal learning dynamics: it converts weekly engagement indicators into latent states, groups full state sequences into learner trajectories, and lets you test a manual state sequence against the discovered patterns.
